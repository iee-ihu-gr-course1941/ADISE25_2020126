Τάβλι "Φεύγα" -  (Εργασία ΑΔΙΣΕ)

Η παρούσα εφαρμογή υλοποιεί το παιχνίδι "Φεύγα" σε περιβάλλον Web. Υποστηρίζει παιχνίδι μεταξύ δύο παικτών είτε στον ίδιο υπολογιστή (Single PC) είτε μέσω δικτύου (Online Multiplayer).
Η εφαρμογή βασίζεται σε αρχιτεκτονική Web API με χρήση PHP για το Backend και JavaScript (jQuery/AJAX) για το Frontend, ενώ η κατάσταση του παιχνιδιού αποθηκεύεται σε βάση δεδομένων MySQL.


 

🛠 Τεχνολογίες που χρησιμοποιήθηκαν

Backend: PHP
Database: MySQL / MariaDB
Frontend: HTML5, CSS3, JavaScript (ES6)
Libraries: jQuery (AJAX polling), Bootstrap 4 (UI components)
Server: Apache (XAMPP ή περιβάλλον users.iee.ihu.gr)




🎲 Κανόνες Παιχνιδιού (Φεύγα)

Υλοποιούνται οι πλήρεις κανόνες της Φεύγας:
- Στήσιμο: 15 πούλια του Λευκού στη θέση 24 και 15 πούλια του Μαύρου στη θέση 12.
- Κατεύθυνση: Και οι δύο παίκτες κινούνται αντίστροφα προς τη φορά του ρολογιού.
- Κανόνας "Μάνας": Ο παίκτης πρέπει να κουνήσει το πρώτο του πούλι (Μάνα) και να περάσει την αφετηρία του αντιπάλου πριν μπορέσει να κουνήσει οποιοδήποτε άλλο πούλι. Στην πρώτη ζαριά κάθε παίκτη, επιτρέπεται μόνο   μία κίνηση (moves_left=1).
- Πιάσιμο θέσης: Μία θέση θεωρείται "πιασμένη" αν υπάρχει έστω και ένα πούλι του παίκτη. Ο αντίπαλος δεν μπορεί να πατήσει σε πιασμένη θέση.
- Μάζεμα (Bearing Off): Ξεκινά μόνο όταν και τα 15 πούλια βρίσκονται στο τελευταίο τεταρτημόριο (θέσεις 1-6 για Λευκά, 13-18 για Μαύρα).
- Ένα πούλι βγαίνει αν το ζάρι είναι ίσο ή μεγαλύτερο από την απόσταση εξόδου.
- Βαθμολογία:
  Απλή Νίκη (+1): Ο παίκτης μαζεύει όλα τα πούλια ενώ ο αντίπαλος έχει ήδη ξεκινήσει το μάζεμα.
  Διπλή Νίκη (+2): Ο παίκτης μαζεύει όλα τα πούλια πριν ο αντίπαλος προλάβει να φέρει όλα τα πούλια του στο "σπίτι".



  
🏗 Αρχιτεκτονική & Δομή API
Η εφαρμογή λειτουργεί ως Web Service. Ο "τροχονόμος" tavli.php δέχεται τα αιτήματα και τα δρομολογεί:

1. Board (tavli.php/board/)
GET: Επιστρέφει την τρέχουσα κατάσταση των 24 θέσεων του ταμπλό.
POST: Καθαρίζει το ταμπλό και κάνει reset την παρτίδα.
2. Status (tavli.php/status/)
GET: Επιστρέφει την κατάσταση του παιχνιδιού (status, p_turn, dice, score, moves_left).
POST: Εκτελεί ενέργειες όπως roll_first, move, pass, collect, play_again.
3. Players (tavli.php/player/)
GET /W ή /B: Επιστρέφει τα στοιχεία του Λευκού ή του Μαύρου παίκτη.
PUT: Εγγράφει έναν παίκτη στη βάση με το όνομά του και παράγει μοναδικό token.




🗄 Βάση Δεδομένων
Το σχήμα της βάσης περιλαμβάνει 3 κύριους πίνακες:
board: Αποθηκεύει τη θέση x, το χρώμα και το πλήθος των πουλιών.
players: Αποθηκεύει το username, το token, το χρώμα και το last_action (timestamp).
game_status: Κεντρικός πίνακας για τη ροή (ποιος παίζει, ζάρια, πούλια που βγήκαν, σκορ).

Stored Procedures: clean_board(): Επαναφέρει το ταμπλό στην αρχική θέση "Φεύγας" και μηδενίζει τα status (εκτός από το συνολικό σκορ αν επιλεγεί επανεκκίνηση).




🎮 Λειτουργίες Frontend (UX)
- Polling: Η JavaScript ανανεώνει το ταμπλό κάθε 3-5 δευτερόλεπτα για να συγχρονίζει τους παίκτες στο Online mode.
- Timer: Κάθε παίκτης έχει 2 λεπτά για την κίνησή του. Αν ο χρόνος λήξει, η σειρά περνάει αυτόματα στον αντίπαλο.
- Interactive UI: Τα πούλια είναι κλικαρίσιμα. Με την επιλογή ενός πουλιού, πρασινίζουν οι έγκυρες θέσεις (suggestions).
- Safe Exit: Όταν ένας παίκτης αποχωρεί, ενημερώνεται ο αντίπαλος και η βάση καθαρίζει αυτόματα από "zombie" παιχνίδια.
- Handshake Restart: Στο τέλος του παιχνιδιού, απαιτείται η συμφωνία και των δύο παικτών για να ξεκινήσει νέα παρτίδα με το ίδιο σκορ.




🚀 Εγκατάσταση & Χρήση
1. Κάντε clone το repository.
2. Εισάγετε το αρχείο tavli.sql στη MySQL σας.
3. Ρυθμίστε τα στοιχεία σύνδεσης στο lib/db_upass.php.
4. Ανοίξτε τη σελίδα index.php στον browser.
5. Επιλέξτε Mode και ξεκινήστε το παιχνίδι.




🛡 Ασφάλεια
Token-based Auth: Κάθε παίκτης ταυτοποιείται με μοναδικό token.
Server-side Validation: Κάθε κίνηση ελέγχεται από την PHP για το αν είναι νόμιμη, αποτρέποντας "πειραγμένα" αιτήματα από το frontend.
Lap Control: Αυστηρός έλεγχος ώστε τα πούλια να μην κάνουν ποτέ κύκλους πάνω από την αφετηρία τους.
